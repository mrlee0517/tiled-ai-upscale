# 机械处理与文件约定

以skill目录下 `scripts/grid_upscale.py` 为入口。Python换成已安装Pillow、NumPy的运行时，路径按实际情况填写。

```bash
python scripts/grid_upscale.py prepare --source /absolute/input.jpg --scale 6 --work /absolute/work/upscale
```

默认4行4列，`--rows` / `--cols` 可改。`--context` 指原图像素，默认最小核心边长的约19%。裁图在原图范围内取上下文，输出 `r1_c1_source.png` 等，以及 `manifest.json`。核心边界共享同一套取整规则，非整除尺寸不会丢行、重行。透明源alpha单独保留，最终按原始alpha放大恢复透明度。

对每个source先查看，再分别用内置image_gen修复。将选定结果复制为同目录下 `r1_c1_ai.png` 等。保持裁图长宽比；实际输出大小由工具决定，不能靠提示词假设模型返回了指定像素数。明显构图漂移应重做；脚本对超过2%的长宽比变化会报错。

```bash
python scripts/grid_upscale.py assemble --work /absolute/work/upscale --output /absolute/outputs/photo_6x
```

先在最多4倍、最长边8192的工作画布融合，使用磁盘映射降低累积数组内存需求；输出尺寸仍遵循目标倍数。`--working-max-edge` 可调，按资源和实际AI细节量选择。脚本报告目标像素数、基础画布内存及磁盘空间；极大目标先评估资源，可换流式图像工具，不能默默减少用户倍数。每块从同一连续画布按全局坐标采样，避免独立插值造成边界相位不一致。

输出 `<前缀>.png`、不透明图的 `<前缀>.jpg`、`<前缀>_preview.jpg`、`<前缀>_report.json`；工作目录保存目标尺寸图块、融合工作图和QA裁图。文件已存在会报错，使用新的前缀，避免覆盖已确认版本。

## 拼合前对齐与防双影

- 长宽比变化低于报错阈值也可能产生明显重影。将AI块对照原图检查整体位移、旋转、拉伸及局部轮廓漂移；需要时先做几何配准，再融合。保留配准方法和参数记录，配准后复查脸、手等结构是否被扭曲。
- 不对错位边缘做宽范围透明叠加，也不将带错位轮廓的原图低频层直接叠回。色调匹配与几何对齐分开处理；完整对象优先选一个合格图块提供高频轮廓，可用避开主体边缘的接缝和分频融合平滑色调。
- `assemble` 的色调匹配和羽化本身不能证明轮廓已对齐。默认输出若出现双影，必须调整拼合流程或修复相应上下文后重新导出，不能直接交付。

## 局部修补

修补参考包含完整手掌、手腕、所有可见手指及接触对象。生成后目视追踪结构，选择合格轮次，制作白修复/黑保护的灰度蒙版（可羽化）。蒙版与修补图须同尺寸。

`--repairs /absolute/repairs.json` 按顺序应用局部修补。坐标全部是**EXIF转正后原图坐标**，记录到最终报告；路径相对repairs.json所在目录解析。示例：

```json
[
  {
    "id": "ear-hand-round-2",
    "image": "ear-hand-approved.png",
    "mask": "ear-hand-mask.png",
    "box": [768, 544, 1152, 928],
    "protected_boxes": [[1005, 600, 1105, 700]]
  }
]
```

box与生成参考裁图精确对应。protected_boxes例如脸部，修补前后像素哈希不一致就报错；保护框不能与实际蒙版羽化区重叠。全部修补完成后再导出、再检查，不能只提供独立修补样张。

## 最终原尺寸局部检查

`--qa /absolute/qa.json` 指定主体QA框（原图坐标），脚本从**最终保存的PNG**直接裁出，不缩放：

```json
[
  {"id": "whole-ear-hand", "box": [800, 620, 1020, 850]},
  {"id": "extended-hand", "box": [1540, 576, 1824, 824]}
]
```

未提供qa时只有自动边界裁图；有人时还须补充脸和完整手的框。QA裁图生成成功不代表内容合理，代理必须实际查看。另存提示词记录和目视结论，说明具体剩余问题。

双影QA须包含高反差主体边缘、全部可见手部、每条拼缝及局部修补边缘，同时抽查块内区域。裁图过大被查看器缩小时继续裁小，按最终实际像素追踪单一轮廓。发现重影后保留同坐标的修复前后对比，并从最终保存整图复查；报告记录实际检查区域、结果和剩余双影，未通过时不得标为合格成品。
